# Final results and reproducibility

The retrospective 2006–2024 analysis is reproduced by one command:

```bash
python -m pip install -r requirements.txt
python src/run_pipeline.py
```

This offline default reconstructs pollster quality, all poll-level weights,
the 2006–2020 calibration, and the 2022/2024 polling forecasts. It then joins
the committed market probabilities and certified outcomes, fits the 2022
hybrid, runs the locked-spec 2024 evaluation, repeats the fixed 50,000-draw
race-cluster bootstrap, and writes the final tables and figures.

To include the checksum-pinned raw-market acquisition and normalization from
the preceding stage in the same command, run:

```bash
python src/run_pipeline.py --rebuild-markets
```

The raw files remain in the gitignored verified cache and are not redistributed
by this repository. An offline cache or pinned local checkout can be supplied
with the market-source options documented by `python src/run_pipeline.py -h`.

## 2022 development fit

The development sample contains 34 PRIMARY race–horizon observations. Each of
the four horizons receives one quarter of the Brier objective. The four Georgia
post-general-runoff observations are generated by the polling pipeline but
cannot enter this fit.

| Estimate | Value |
| --- | ---: |
| Unconstrained polling weight | -0.337005 |
| Constrained polling weight | 0.000000 |

The unconstrained optimum is negative. Applying the prespecified convex bound
therefore places the constrained solution at zero, so the frozen hybrid equals
the market forecast.

## Locked-spec 2024 evaluation

| Model | Equal-horizon Brier | Equal-horizon log loss |
| --- | ---: | ---: |
| Polling | 0.087484 | 0.283330 |
| Market | 0.076103 | 0.268463 |
| Frozen hybrid | 0.076103 | 0.268463 |

Polling minus market is +0.011381 for Brier score and +0.014867 for log loss;
positive values mean the market has lower loss. Both whole-race clustered
bootstrap intervals include zero:

| Paired difference | Point estimate | 95% percentile interval |
| --- | ---: | ---: |
| Brier | 0.011381 | [-0.011233, 0.035584] |
| Log loss | 0.014867 | [-0.043708, 0.072087] |

The two forecasts favor the same party in 58 of 60 observations. Their
probability correlation is 0.973 and their logit correlation is 0.904. The
only favorite-party disagreements are Ohio at 14 and 7 days.

These results support a narrow conclusion: in this architecture and sample,
adding the polling probability did not improve the frozen convex ensemble.
They do not show that polling contains no predictive information. The 2024
comparison is retrospective, the sample contains only 18 race clusters, and
the aggregate loss difference remains imprecise. The planned 2026 application
is the prospective test.

## Automated checks and presentation outputs

The end-to-end command fails closed if any frozen membership, calibration,
forecast, fit, score, bootstrap stream, anomaly flag, or favorite-party
diagnostic changes. It generates:

- a machine-readable nested audit and compact CSV tables;
- the 2022 hybrid-weight objective figure;
- 2024 Brier and log-loss comparisons by horizon;
- a paired polling-versus-market probability figure in PNG and SVG formats.

Continuous integration compiles the source, runs the full unit/regression test
suite, executes the offline end-to-end command, and retains its tables and
figures as a workflow artifact.
